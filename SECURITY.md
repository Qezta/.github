# Security policy

This is the default policy for every [Qezta](https://github.com/Qezta)
repository that doesn't have its own.

## Reporting a vulnerability

Please report vulnerabilities privately, either by emailing
**security@qezta.com** or through the repository's
**Security → Report a vulnerability** form (GitHub private advisories).
Don't open a public issue.

Include what's affected, how to reproduce it, and the impact you expect.
You'll get an acknowledgement as soon as possible, and we'll keep you
updated until it's fixed.

## Scope

The code in Qezta repositories. Report vulnerabilities in third-party
dependencies to their maintainers.
